# CRUD de Estudiantes

Proyecto web sencillo para registrar, consultar, actualizar y eliminar estudiantes.

## Tecnologias usadas

- Python
- SQLite
- HTML y CSS

## Como ejecutar

1. Ejecutar el proyecto:

```bash
python app.py
```

2. Abrir en el navegador:

```text
http://localhost:8000
```

## Funciones principales

- Crear estudiantes.
- Listar estudiantes registrados.
- Ver el detalle de un estudiante.
- Editar informacion de estudiantes.
- Eliminar estudiantes.

## Flujo de trabajo

El proyecto se desarrollo usando ramas `feature/` y `hotfix/`, con integracion hacia `developer`, `qa` y `main`.
